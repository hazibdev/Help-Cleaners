# 🧹 Help Cleaners — Professional House Cleaning Toronto

A modern, responsive landing page for a Toronto-based professional cleaning service. Built with performance, accessibility, and mobile-first design in mind.

## Features

- **12 complete sections**: Header, Hero, Trust Bar, Services, Why Choose Us, Before/After Slider, Process, Testimonials, FAQ, CTA, Contact, Footer
- **Mobile-first responsive design** with breakpoints at 576px / 768px / 1024px
- **Before/After image comparison slider** with drag and touch support
- **Smooth scroll-triggered animations** via IntersectionObserver
- **Counter animations** on the Trust Bar
- **Horizontal scroll testimonials** with snap-scroll and dot indicators
- **FAQ accordion** with smooth expand/collapse
- **Full-screen hero** with zoom effect and gradient overlay
- **Eco-friendly brand vibe** with Navy (#1F2942) / Gold (#D9A826) color scheme

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — No frameworks or jQuery
- **Google Fonts** — DM Serif Display (headings) + Inter (body)
- **SVG icons** — Inline throughout

## Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/hazibdev/help-cleaners.git
   ```

2. **Open in browser**
   Just open `index.html` in any modern browser — no build step required.

3. **Customize**
   - Replace images in the `images/` folder with your own
   - Update phone number, email, and business hours in the contact section
   - Add your Google Maps embed URL to the map iframe
